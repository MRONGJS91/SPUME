# MetaShift Dataset

Place the MetaShift dataset here.

## Expected directory layout

```
datasets/metashift/
├── cat/
│   ├── couch/          # cat images with "couch" context
│   │   ├── xxx.jpg
│   │   └── ...
│   ├── bed/            # cat images with "bed" context
│   │   └── ...
│   └── ...
├── dog/
│   ├── grass/          # dog images with "grass" context
│   │   └── ...
│   ├── beach/          # dog images with "beach" context
│   │   └── ...
│   └── ...
├── metadata_metashift_catdog.csv   # generated by build_metashift_metadata.py
├── vit_gpt2_img_embeddings.pickle  # generated by extract_concepts.py
├── vit_gpt2_vocab.pickle
├── blip_img_embeddings.pickle
└── blip_vocab.pickle
```

## How to obtain MetaShift

1. Download from the official repository:
   https://github.com/Weixin-Liang/MetaShift

2. Extract the Cat vs Dog subset (or any other subset) into this directory.

3. Run the metadata builder:
   ```
   python scripts/metashift/build_metashift_metadata.py \
       --data-root datasets/metashift \
       --subset-name metashift_catdog
   ```
